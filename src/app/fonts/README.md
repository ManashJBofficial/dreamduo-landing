# Landing fonts

Self-hosted Latin WOFF2 files from Google Fonts, under the included SIL Open Font
Licenses. Manrope contains the 400-700 weight range; Bricolage Grotesque uses the
700 heading weight at its original default optical size of 14.

- Manrope: https://fonts.google.com/specimen/Manrope
- Bricolage Grotesque: https://fonts.google.com/specimen/Bricolage+Grotesque

Both fonts are preloaded and use `font-display: swap`. The compact files retain
the site's typography without a build-time connection to Google Fonts.
